# Portfolio — Adam Jakubowski

Lekka strona statyczna bez frameworków i panelu administracyjnego.

## Najprostsza edycja
Otwórz `content.js` i zmień teksty między cudzysłowami. Układ i wygląd pozostaną bez zmian.

## Podgląd lokalny
W folderze strony uruchom:

    python3 -m http.server 8080

Następnie otwórz http://localhost:8080

## Publikacja
Najprościej: GitHub Pages albo Cloudflare Pages. Oba obsługują własną domenę i HTTPS bez opłat dla takiej strony.

## Przed publikacją
1. Zmień `kontakt@twoja-domena.pl` w `content.js`.
2. Zastąp anonimowe projekty tylko materiałami, na których publikację masz zgodę.
3. Dodaj politykę prywatności, jeśli uruchomisz formularz, statystyki albo cookies.
4. Zoptymalizuj fotografie do WebP (najlepiej 1600 px, zwykle <300 KB).
